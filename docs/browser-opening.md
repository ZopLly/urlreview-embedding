# Открытие сайта из терминала

Запрос пользователя: открывать сайт по клику либо просматривать его в терминале.

Выбран минимальный вариант: открытие в стандартном браузере Linux по клавише O или клику на домен. Встроенный браузер в терминале не добавляется: для реальной проверки нужен обычный браузер с JavaScript/изображениями. Решение остаётся ручным, чтение/сохранение CSV не меняется.

- Голый домен открывается с https://; явные http:// и https:// сохраняются.
- Другие схемы и управляющие символы отклоняются. URL передаётся одним аргументом в xdg-open, без shell.
- Открытие асинхронное, описание/позиция остаются на месте, ошибки запуска видны в статусе.
- Нет автоматических открытий, загрузки описаний, передачи CSV или предпросмотра.
- Клик поддерживается в терминалах с mouse reporting; O работает без поддержки мыши.
- Колесо мыши прокручивает текст и списки. Клик вне домена не открывает сайт.

Порядок: тесты URL/запуска и PTY-клавиши/мыши → реализация → полный прогон → обновление инструкции/архива. Все браузерные тесты используют локальную заглушку xdg-open, настоящие страницы не открываются.
