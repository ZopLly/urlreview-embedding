# Разметка похожих записей

По запросу пользователя показываем номер записи (без заголовка), номер строки таблицы (с заголовком), решение action и итоговые категории в списке и подробностях. Номер строки таблицы не является физическим номером строки текстового CSV: описание может содержать переносы.

Итог при OK — исходный class и дополнительные label; при ERROR — только label, пустой label означает «не определены»; при NOT_DESC — только явно указанный label, иначе «не определены», с предупреждением о недостаточном описании. Это представление сохранённого решения, не новая автоматическая разметка. CSV, индекс и правила сохранения не меняются.

Пять строк на пример: номер/домен/сходство; строка таблицы и решение; итог; фрагмент/предупреждение; отступ. Подробности показывают также исходные class и label полностью. Длинные итоги могут обрезаться в списке, Enter открывает полный текст с прокруткой.
