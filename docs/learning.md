# Учимся через рабочее приложение

Рабочая основа реализована помощником по согласованным требованиям. Учебный `main.c` ученика остаётся отдельно. Цель — сначала пользоваться инструментом, а затем осваивать C небольшими изменениями, не откладывая разметку до освоения всех тем.

## Первое упражнение: изменить одну подпись

1. Запустите демо через `./scripts/run-demo.sh` и найдите на экране надпись «Исходный class».
2. Откройте `src/ui.c`, найдите функцию `render` и эту надпись.
3. Измените её, например, на «Прогноз модели». У подписи есть отведённая ширина, поэтому длинная фраза может потребовать сдвига соседнего значения.
4. Сохраните файл, выполните `make`, снова запустите демо.
5. Объясните, почему без пересборки старая программа не изменится.

Это упражнение меняет только вывод, не логику разметки. Работайте с demo, не с настоящим CSV.

## Второе упражнение: пройти путь решения

Найдите `choose_categories`, затем `confirm`, затем `store_commit`. Пока достаточно понять последовательность: пользователь выбирает → проверяет итог → программа меняет два поля → записывает рабочую копию. Не нужно разбирать каждый указатель за один вечер.

## Затем по одному занятию

- Структура `Row`: одна CSV-запись содержит массив строк. Почему её позиция надёжнее домена, который может повторяться.
- Структура `Table`: хранит записи и позиции столбцов. Почему нельзя всегда считать description пятым столбцом.
- Результат `bool` и строка ошибки: как вызывающая функция узнаёт о неудаче и почему нельзя показывать «сохранено» раньше времени.
- Указатель и владение памятью: кто выделил строку, кто её освобождает и почему нельзя использовать освобождённый адрес.
- Парсер CSV: разделитель внутри кавычек является текстом; конец физической строки не всегда конец записи.
- Тест: добавить вымышленный случай, воспроизвести ошибку, исправить и снова проверить.

## Эмбеддинги — отдельная короткая тема

Текст → числовой вектор → сравнение векторов → похожие проверенные сайты. Векторы рассчитывает готовая модель; накопление размеченных сайтов увеличивает набор примеров, а не автоматически обучает модель. Косинусное сходство — мера близости, не процент уверенности. Подключение этого компонента не требует переписывать ручной сценарий.
