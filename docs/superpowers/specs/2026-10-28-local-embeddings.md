# Локальный поиск похожих записей

Пользователь подтвердил локальную multilingual-e5-small, команду «Похожие» и поиск среди уже проверенных строк. Разработка ведётся на вымышленных данных; рабочие CSV помощник не читает. Пользователь продолжает разметку старым процессом. Эмбеддинги не назначают категории.

Выбор реализации помощника: оставить интерфейс/поиск на C, вычисление векторов вынести в отдельный Python CLI с ONNX Runtime CPU и tokenizers. Это легче переносить и обслуживать, чем встраивать токенизацию/ONNX C API; модель в памяти только при подготовке индекса. Полностью Python-интерфейс потребовал бы переписывания работающего приложения. Модель скачивается отдельной явной командой с Hugging Face; вычисление и поиск работают офлайн.

Первый вариант: очищать только пробелы, разбивать весь текст на перекрывающиеся окна токенов, усреднять нормализованные векторы фрагментов и нормализовать результат. Пустое описание — нулевой вектор, в поиске не участвует. Поиск — точное косинусное сходство всех ненулевых векторов, 5 результатов только с допустимым непустым action; текущая запись исключена. Показать domain, class, label, action, короткий фрагмент, коэффициент сходства (не процент уверенности); Enter открывает полное описание. NOT_DESC показывается явно как недостаточное описание, не как эталон категории.

Индекс не содержит разметку: актуальные action/label берутся из открытой рабочей копии. Проверяются число/порядок строк и fingerprint domain+description; индекс остаётся годен при ручных изменениях action/label. Индекс с несовпадающими описаниями отклоняется. Нет сетевых запросов из интерфейса и генератора индекса. Формат бинарный, версионированный; ограничения размера, размерности, конечности и норм векторов; сохранение через temp+replace. --embeddings PATH опционален; отсутствие индекса не мешает разметке.

Установка зависимостей и скачивание модели относятся к разрешённой пользователем реализации локальной системы. Исходный файл и учебный main.c не меняются. Тестирование реальной модели — только на синтетических русских текстах. Замер скорости, границы качества, воспроизводимый запуск и учебное объяснение входят в поставку. Модель не обучается от добавления разметки; растёт набор доступных примеров.
