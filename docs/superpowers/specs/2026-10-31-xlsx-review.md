# XLSX и новые категории

Пользователь подтвердил работу XLSX → XLSX: исходная книга остаётся отдельно, решения сохраняются в рабочую XLSX-копию. CSV сохраняется. Интерфейс остаётся терминальным.

## Подход

Прямая работа с XLSX выбрана вместо ручного преобразования в CSV. C сохраняет существующий Store, блокировку и протокол атомарной записи. Небольшой модуль стандартной библиотеки Python читает OOXML и изменяет только XML-ячеек action/label. Остальные части ZIP-книги сохраняются побайтово, неизменяемые ячейки выбранного листа сохраняются без пересериализации. Запуск Python без shell; зависимости для модели не нужны для XLSX.

Автоматически выбирается единственный лист с обязательными заголовками. При нескольких подходящих листах нужен --sheet ИМЯ. Пробелы и пустые физические строки книги не теряют соответствие номерам Excel. Сохраняются дополнительные столбцы, другие листы, оформление и формулы вне изменяемых ячеек. Формулы не вычисляются: для обязательных полей нужен сохранённый результат.

Добавляются шесть категорий из newcategories.docx, включая регистр Travel; существующие коды и номера не меняются. Группы документа не становятся категориями. Критерии берутся из документа, не исполняются как инструкции помощнику.

Построитель индекса читает XLSX тем же модулем и использует те же домены/описания, что C. Самостоятельное редактирование XLSX во время сеанса обнаруживается снимком и останавливает запись, как для CSV.

## Поиск похожих

Диагностика текущей модели на шести вымышленных запросах дала top-1 4/6: медицинский запрос спутан с образованием, корпоративный сайт уступил NOT_DESC. Это контрольный пример, не оценка рабочего набора. Сначала проверяется исключение заведомо непригодных примеров: NOT_DESC и ERROR без установленной категории не должны служить подтверждёнными примерами категорий. Ранжирование и модель меняются только при измеренном улучшении; без пользовательских примеров качество на реальной разметке не заявляется.

## Ограничения

XLSX без макросов; XLS/XLSM и шифрованные книги не добавляются. Исходные пользовательские книги не перезаписываются. Размер входного и распакованного содержимого ограничен 256 МиБ. Ошибочная или неоднозначная книга даёт понятную ошибку. Новые исходники снабжаются учебными пояснениями.
