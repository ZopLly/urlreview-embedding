# XLSX Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Добавить новые категории и рабочий сценарий XLSX → XLSX, проверить качество похожих примеров.

**Architecture:** C хранит таблицу и атомарно сохраняет байты. Python stdlib-модуль отвечает за OOXML и сохранение неизменённых частей книги. Модель остаётся локальной и необязательной.

**Tech Stack:** C17, ncursesw, Python 3 stdlib zipfile/XML, существующий ONNX Runtime.

**Spec:** docs/superpowers/specs/2026-10-31-xlsx-review.md

## Global Constraints

- Исходные пользовательские книги не перезаписываются; существующие незакоммиченные пояснения сохраняются.
- Фиксируется точный код Travel из документа, без автоматического перевода в нижний регистр.
- Размер входного и распакованного содержимого ограничен 256 МиБ.
- Работать в текущем implementation/url-review; без переноса прежних незакоммиченных правок и без автоматического коммита.
- Документированные решения пользователя XLSX → XLSX выполняются без повторного запроса того же разрешения.

## Review Focus

- Длинный текст, sharedStrings и разреженные строки Excel: не потерять данные и номера строк.
- Книга с несколькими подходящими листами: не выбрать чужой лист молча.
- Стиль и формулы: менять только реально изменившиеся action/label.
- Ошибка дочернего Python или внешняя правка: не заменить рабочую копию и не перейти дальше.
- Эмбеддинги: не принять NOT_DESC за подтверждённую категорию и не заявить качество без измерения.

## Результат

- Категории: тест сначала выявил отсутствие кодов; после добавления шести строк и разрешения регистра Travel test-guide проходит. Всего 65 категорий.
- XLSX: первые интеграционные тесты падали на неизвестном --sheet и попытке прочесть ZIP как UTF-8. Backend и C-интеграция устранили оба отказа.
- Индекс XLSX: тест сначала выявил отсутствие параметра sheet, затем подтвердил совместимость Python-индекса с C.
- Отбор примеров: тест воспроизвёл включение NOT_DESC и ERROR без label, затем подтвердил их исключение. Синтетический top-1 4/6 → 5/6; ошибка медицина/образование остаётся.
- Независимое чтение кода обнаружило четыре существенных особенности OOXML: комментарии/чужие namespace, связанные формулы, пустой cached string и расположение sharedStrings по связи. Для каждой добавлен сначала падающий тест; после исправления все проходят. Ячейки формульной группы безопасно отклоняются вместо повреждения.
- Пользователь отказался исправлять две прежние книги: никаких исправленных копий не создано. MAINTRAIN_checked.xlsx прочитан только для проверки, без записи: 5037 записей, 244 проверены, лист MAINTRAIN_backup.
- Итог: make test — C-проверки и 40 Python-тестов OK; make sanitize — ASan/UBSan OK; git diff --check — без ошибок.
- Существующие незакоммиченные учебные пояснения и пользовательские изменения сохранены. Автоматический коммит, перенос рабочей директории, скачивание другой модели и изменение исходных книг не выполнялись.

- Для MAINTRAIN_checked.xlsx локально построен results/MAINTRAIN.uremb: 5037 векторов, 631.20 с. Исходная книга совпала по SHA-256 с состоянием до завершения расчёта; размер индекса соответствует формату.
